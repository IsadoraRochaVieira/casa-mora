# Matriz de responsabilidades

Legenda: **R** executa; **A** aprova/responde; **C** consulta; **I** informada.

| Atividade | Sócias/produto | Tecnologia | LGPD/DPO | Cibersegurança | Clínica |
|---|---|---|---|---|---|
| Decidir dados necessários | A/R | C | C | I | C |
| Arquitetura e implementação | A | R | C | C | I |
| Bases legais e documentos | A | C | R | I | C |
| RIPD e retenção | A | C | R | C | C |
| Limites e respostas da Júlia | A | R | C | C | R/C |
| Testes de segurança | A | C | C | R | I |
| Correção de vulnerabilidades | A | R | I | C/reteste | I |
| Aprovação do lançamento | A/R | C | C | C | C |
| Resposta a incidente | A | R | R | R | C, se aplicável |
| Atendimento às titulares | A | C | R | I | I |

## Governança mínima

- Reunião mensal de 45 minutos das sócias para riscos, acessos, incidentes e fornecedores.
- Registro de cada decisão que altera coleta, IA, voz, ciclo, relatórios ou publicidade.
- Nenhum fornecedor novo entra antes de preencher o mapa de dados.
- Nenhuma pessoa recebe acesso administrativo sem conta individual e necessidade documentada.
- Mudanças de alto risco não são aprovadas pela mesma pessoa que as implementou sem revisão.
